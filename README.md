# Excel 拆表工具

按关键列拆分数据行，或按关键行拆分数据列。每个关键字生成一个独立文件，或合并为一个工作簿中的多个工作表，可保留固定表头、表尾或左右固定列。

## 使用

安装依赖后运行：

```powershell
python -m pip install -r requirements.txt
python .\src\excel_splitter.py
```

界面左侧选择源文件、工作表和输出目录，设置拆分方式、固定行列数及关键行列序号；右侧预览表格并列出全部拆分对象，确认后点击“开始拆分”。固定行列数允许为 0，关键行列序号从 1 开始。

- 单击预览的列标题可设为关键列（按行拆分时单击某一行设为关键行）；右键单击行或列，可直接设为表头、表尾或左右固定列的分界。
- 在“拆分对象”中勾选需要输出的分组，支持全选、全不选、反选；列表实时显示每个分组将生成的文件名或工作表名。
- 输出方式可选“每个对象一个文件”，或“合并为一个工作簿”（生成 `源文件名_拆分.xlsx`，每个对象一个以关键字命名的工作表）。
- 文件命名规则默认为 `{文件名}_{关键字}`，可用 `{文件名}`、`{关键字}`、`{序号}`、`{工作表}` 组合，例如 `{序号}_{关键字}_2026Q3`；`{序号}` 按输出顺序编号并自动补零。
- 读取、预览和拆分在后台进行。调整参数时不会重复读取同一文件，`.xls` 等需要转换的文件也只转换一次；文件在外部保存后会自动重新读取，“重新读取”（F5）总是重新打开文件。
- 拆分时显示进度，可随时取消；取消或失败都不会留下本次的输出文件。完成后可直接打开输出目录。
- 界面会记住拆分方式、行列参数、输出方式、命名规则和上次打开的文件夹（Windows 保存在 `%APPDATA%\ExcelSplitter\settings.json`）。选择其他位置的源文件时，自动生成的输出目录随之更新，手动指定的目录保持不变。
- 快捷键：Ctrl+O 打开文件，F5 重新读取，Ctrl+Enter 开始拆分，Esc 取消拆分。

预览只显示部分行列，实际拆分处理整个工作表。输入无效参数或命名规则时会显示具体原因，不会暗中改用另一个参数。空白关键字单独成组；文字两端空格会忽略，数字与相同文字表示的关键字会归为同组，`3.0` 与 `3` 等数值按 Excel 常规格式的显示值归组，日期关键字按 `2026-09-25` 形式分组和命名。

按关键列拆分：

```powershell
python .\src\excel_splitter.py --input "分配表.xlsx" --sheet "分配" --header-rows 3 --footer-rows 1 --key-column 7
```

按关键行拆分：

```powershell
python .\src\excel_splitter.py --input "季度统计.xlsx" --mode row --header-cols 1 --footer-cols 1 --key-row 2
```

只列出拆分对象、只输出部分分组、自定义文件名，或合并为一个工作簿：

```powershell
python .\src\excel_splitter.py --input "分配表.xlsx" --header-rows 3 --key-column 7 --list-groups
python .\src\excel_splitter.py --input "分配表.xlsx" --header-rows 3 --key-column 7 --group 财务部 --group 人事部 --name-template "{序号}_{关键字}_2026Q3"
python .\src\excel_splitter.py --input "分配表.xlsx" --header-rows 3 --key-column 7 --single-workbook
```

| 参数 | 含义 |
| --- | --- |
| `--input` | 输入文件；命令行运行必须提供 |
| `--sheet` | 工作表名称；默认第一个数据工作表 |
| `--mode` | `column` 拆数据行（默认），`row` 拆数据列 |
| `--header-rows` / `--footer-rows` | column 模式的固定表头、表尾行数；表尾默认 0 |
| `--key-column` | column 模式的分组关键列 |
| `--header-cols` / `--footer-cols` | row 模式的左右固定列数；右侧默认 0 |
| `--key-row` | row 模式的分组关键行 |
| `--output-dir` | 输出目录；默认源文件旁的 `split_output` |
| `--group` | 只输出该关键字的拆分对象，可重复使用；关键字不存在时报错 |
| `--name-template` | 文件命名规则，默认 `{文件名}_{关键字}` |
| `--single-workbook` | 合并为一个工作簿，每个拆分对象一个工作表；不能与 `--name-template` 同时使用 |
| `--list-groups` | 只列出拆分对象及其行列数，不生成文件 |

命令行缺少必要参数时会返回错误，不会意外启动图形界面。

## 输出和保留范围

- 输出统一为真正的 `.xlsx` 工作簿，只包含选中的工作表；隐藏的源表在输出中设为可见。
- 支持 `.xlsx`、`.xltx`，以及不含 VBA 的 `.xlsm`、`.xltm`、部分 xlsx 内核的 `.et`。模板输出会正确转成普通工作簿。
- `.xls` 和非 xlsx 内核的 `.et` 需要本机 LibreOffice 或 Excel/WPS 转换器。旧格式转换后的保真度取决于转换器，请核对复杂文档。
- 保留单元格格式、富文本、批注、链接、行高列宽、隐藏和分组属性、工作表保护、主题和日期系统。
- 合并区域会随保留行列收缩，原合并区域起始行列被删除时仍保留其文字和格式。
- 调整打印区域、打印标题、冻结位置、分页、筛选范围及筛选列序号；复制普通条件格式和数据验证并调整其范围与公式。
- 合并为一个工作簿时，工作表以关键字命名：去除 `\ / ? * [ ] :` 等非法字符、截断到 31 个字符，重名自动编号。公式、名称、打印区域和筛选按各工作表保留的行列分别调整；公式中带原工作表名的引用改为对应的新工作表，用到的名称转为工作表级名称；打开时只有第一个工作表处于选中状态。
- 文件名含非法字符、过长关键字、大小写重名或已有输出时，自动编号避免覆盖。整批文件先在临时目录保存，保存失败不发布半批结果；最终写入失败时清理本次已写文件。进程被强制终止或断电不属于可回滚的异常。

## 公式及复杂内容边界

公式会按保留的实际行列调整普通 A1 引用、绝对引用、整行整列引用，以及输出公式使用的静态命名区域。字符串文字和函数名不会被误改。范围包含表头或表尾时保留其完整对应区间。

**公式结果由 Excel/WPS 打开文件后重算，本程序不计算公式，也不保留旧计算缓存。** 如果一个公式单独引用了被剔除的单元格，或其整个引用范围都被剔除，输出会明确显示 `#REF!`，需要检查该公式；不会偷偷指向其他数据。使用位置常量的查找公式、复杂相对条件格式等仍需业务核对，不能保证任意 Excel 公式在删行删列后都维持原业务含义。

遇到以下已识别内容会说明原因并停止本次输出，避免静默丢失：

- 分组关键单元格含公式或 Excel 错误值：先在副本中将关键字转换为有效固定值。
- 输出中的公式依赖其他工作表、外部工作簿，或使用无法解析的名称、结构化引用、数组/数据表公式、`INDIRECT` / `OFFSET` 动态引用：先转为值或普通引用。
- VBA 宏、选中工作表中的图表、图片、透视表、Excel 表对象：尚不提供这些内容的完整拆分保留。
- 读取时由底层库明确报告将移除的扩展功能。

普通条件格式和数据验证有回归覆盖；未承诺保留任意嵌入对象、控件或厂商私有扩展。复杂工作簿应保留原文件并核对输出。

## 验证与打包

```powershell
python -m unittest discover -s tests -v
```

测试会自行生成临时输入文件，验证两种拆分方式、公式、合并区域、格式、参数、失败清理，以及分组选择、命名规则、合并工作簿、进度与取消、设置记忆等界面流程，不依赖未提供的样例表。

Windows 运行 `scripts\build_windows.bat`，生成 `dist\ExcelSplitter-Windows\ExcelSplitter-Windows.exe`；Linux 运行 `bash scripts/build_linux.sh`，生成 `dist/ExcelSplitter-Linux`。打包前自动运行测试，失败会停止，不再删除整个 `dist` 或 `build` 目录。打包必须在目标操作系统进行。
